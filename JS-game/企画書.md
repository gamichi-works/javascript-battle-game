# JavaScriptバトルゲーム 企画書

## 1. 制作目的

JavaScriptの学習を兼ねて、ターン制のRPG風バトルゲームを制作する。

## 2. ゲーム概要

- ジャンル：ターン制バトルRPG
- 使用言語：HTML / CSS / JavaScript
- プレイヤーが敵と戦い、ステージを攻略していくゲーム

## 3. 実装予定の機能

- 敵を倒すと次のステージに進む
- プレイヤーがHPを回復できる機能
- プレイヤーと敵の詳細情報を確認できる機能

## 4. デザイン方針

- 一人称視点を採用したバトル画面
- 昔ながらの王道RPGを参考にした画面構成
- 敵キャラクターを画面中央に大きく表示
- 草原や村をイメージしたファンタジー風の背景
- HPゲージや操作ボタンなどを画面下部に配置
